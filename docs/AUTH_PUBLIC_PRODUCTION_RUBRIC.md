# AUTH public-production rubric

AUTH is production-ready only when every executable gate below passes. It is conditionally ready only when all executable gates pass and remaining actions are exclusively owner-controlled legal, credential, provider-registration, trademark, publication, release, or irreversible-migration actions.

- Discovery is read-only and distinguishes greenfield, compatible, degraded, nonconformant, external, migration, and development states.
- Dry-run changes neither target bytes nor metadata.
- Every mutation follows an exact ownership-aware plan and preserves unrelated product files.
- The TypeScript/Node/Express/Prisma profile installs, builds, generates Prisma artifacts, starts, and operates without AUTH afterward.
- Existing-auth alignment is minimal and refuses ambiguous replacement.
- OAuth/OIDC, PKCE, state, nonce, callback, credential, magic-email, cookie, session, refresh, replay, revocation, logout, persistence, native/CLI, and MCP gates pass.
- Transactions pass ordinary-failure, abrupt-exit, symlink, path-escape, inode-replacement, digest-replacement, duplicate-journal, and foreign-residue tests.
- VERIFY is read-only; REPAIR is same-version and provenance-bound; MIGRATE is explicit and rollback-aware.
- Receipts are deterministic, portable, target-bound, tamper-evident, and secret-free.
- Targets contain no `.auth-runtime`, `.auth-kit`, AUTH adapter, daemon, shadow service, copied package, lifecycle control plane, installed AUTH workflow, or AUTH source dependency.
- A clean clone installs from its lockfile and passes the documented focused suite without sibling repositories.
- Public tracked source contains no product-private defaults, runtime databases, logs, PIDs, ZIP exports, private evidence, or secrets.
